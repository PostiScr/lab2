# Проверка и поиск римских чисел

Лабораторная работа № 2 «Регулярные выражения. Unit-тестирование».

Программа проверяет запись римского числа и ищет римские числа в текстовом файле или на веб-странице. Для проверки и поиска используется модуль `re`.

## Поддерживаемый формат

Поддерживаются стандартные записи чисел от 1 до 3999 с символами `I`, `V`, `X`, `L`, `C`, `D`, `M`. При вводе можно использовать строчные буквы. Например, `xiv` и `MCMXCIV` считаются корректными, а `IIII`, `VV` и `IC` — некорректными.

Регулярное выражение последовательно проверяет тысячи, сотни, десятки и единицы. Для сокращённой записи поддерживаются пары `IV`, `IX`, `XL`, `XC`, `CD` и `CM`.

## Установка и запуск

Требуется Python 3.10 или новее. Выполняйте команды из корня репозитория.

```bash
python -m pip install -r requirements.txt
python main.py
```

| Пункт меню | Действие |
|---|---|
| `1` | Проверить введённое римское число |
| `2` | Найти римские числа в локальном текстовом файле UTF-8 |
| `3` | Найти римские числа в тексте HTTP-ответа по URL |
| `0` | Выйти из программы |

### Пример поиска в файле

Создайте файл `example.txt` в корне проекта с таким содержимым.

```text
В году MMXXIII мы прочитали XIV главу. Запись IIII некорректна.
```

Выберите пункт `2` и введите `example.txt`. Программа выведет `['MMXXIII', 'XIV']`. При поиске по URL проверяется весь текст ответа, в том числе HTML-разметка.

## Тестирование

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют корректные и ошибочные записи, поиск в тексте и файле, отсутствие файла, успешный ответ сайта и сетевую ошибку. Чтение файла в тесте успешного поиска и HTTP-запросы подменяются с помощью `unittest.mock`.
